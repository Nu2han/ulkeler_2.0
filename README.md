# 🌍 Hand Gesture Country Info Cards (MediaPipe & OpenCV)

Bu proje; Python, OpenCV ve MediaPipe kullanarak kamera karşısında yapılan **kültürel el hareketlerini (jestleri)** gerçek zamanlı algılayan ve ekrana ilgili ülkeye ait **saydam bilgi kartları (HUD Cards)** basan bir Bilgisayarlı Görü (*Computer Vision*) uygulamasıdır.

## 🚀 Desteklenen Jestler & Ülkeler

- **🇹🇷 Türkiye:** Bozkurt İşareti 🤘 *(Ankara, Kebap, Kız Kulesi)*
- **🇰🇷 Güney Kore:** Finger Heart / Parmak Kalbi 🫰 *(Seul, K-Pop, Kimchi)*
- **🇮🇹 İtalya:** Che Vuoi? / Parmak Birleştirme 🤌 *(Roma, Pizza, Kolezyum)*
- **🇯🇵 Japonya:** Peace / V Sign ✌️ *(Tokyo, Suşi, Anime)*
- **🌺 Hawaii (ABD):** Shaka / Hang Loose 🤙 *(Honolulu, Sörf, Aloha Ruhu)*
- **🇬🇧 İngiltere:** Thumbs Up 👍 *(Londra, Big Ben, Beş Çayı)*
